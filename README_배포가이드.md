# 🌐 WAR-SIM 3D v5.0 — 모바일/PC 모든 기기 URL 배포 가이드

이 압축 파일(`war_sim_3d_2026_web_deploy.zip`)은 **별도 서버나 빌드 과정 없이** 정적 웹 호스팅에 올리기만 하면 **아이폰·갤럭시·아이패드·PC 어디서든 주소(URL)만으로 바로 실행**되는 PWA 웹 앱 패키지입니다.

## 🚀 30초 만에 무료 주소(URL) 만들기 (가장 쉬운 방법 3가지)

### 방법 1. Netlify Drop (회원가입 없이 드래그 앤 드롭 10초 완성)
1. 이 압축 파일의 압축을 풉니다.
2. 브라우저에서 **https://app.netlify.com/drop** 에 접속합니다.
3. 압축을 푼 폴더 전체를 화면에 그대로 끌어다 놓습니다.
4. 즉시 생성되는 `https://xxxx.netlify.app` 주소를 모바일이나 친구에게 공유하면 모든 기기에서 바로 실행됩니다!

### 방법 2. GitHub Pages (영구 무료 주소)
1. GitHub 새 저장소(Repository)를 만들고 압축 푼 파일(`index.html`, `manifest.json` 등)을 업로드합니다.
2. `Settings → Pages → Branch: main → Save`를 누르면 `https://<아이디>.github.io/<저장소명>/` 주소가 생성됩니다.

### 방법 3. Vercel (초고속 글로벌 CDN)
1. **https://vercel.com** 로그인 후 `Add New → Project`에서 폴더/저장소를 연결하면 `vercel.json` 설정으로 즉시 배포됩니다.

## 📱 모바일 앱처럼 전체화면으로 쓰기
- **아이폰(Safari)**: 배포된 주소 접속 → 하단 공유 버튼 → **홈 화면에 추가**
- **안드로이드(Chrome)**: 배포된 주소 접속 → 우측 상단 메뉴 → **홈 화면에 추가 / 앱 설치**
- 두 손가락 핀치 줌, 한 손가락 지구본 회전, 하단 `🛡️ 국가·전력·참전` / `📋 작전·전황·SNS` 드로어 버튼으로 모바일에서도 3D 지구본을 넓게 조작할 수 있습니다.
